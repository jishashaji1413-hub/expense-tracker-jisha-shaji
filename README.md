# Expense Tracker

A simple and responsive web application for managing personal income and expenses.

Users can add, edit, delete, filter, and analyze transactions directly from the browser.

## Features

- Add income and expense transactions
- Enter amount, category, date, and description
- Edit existing transactions
- Delete transactions with confirmation
- View total income, expenses, and current balance
- Filter transactions by type and category
- Sort transactions by date
- View monthly income, expenses, balance, and transaction count
- Visualize expenses using a category-wise doughnut chart
- Form validation with helpful error messages
- Persist transactions using browser Local Storage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Chart.js
- Browser Local Storage
- Google Fonts
